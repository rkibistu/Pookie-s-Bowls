I want to create a very simple app to manage salads and poke bowls for me and my girl.
I want to be as simple as possible: even plain html, js and css if you consider is enough  with soemthing very lite for the database.

## Main ideas:
- beautiful and colorful pages to be more appealing
- a list with a lot of ingredients that can be used, each with different categeroies (protein, base, fresh vegetables/fruits, cooked vegetables/fruit, topping, etc.). An entry can be in more categories if it can be sued in/as both.
- a list with saved recipies (combinations of ingredients) + notes on every recipie

## More details about functionalities

### Ingredient list

I want a page where i can see all the ingredients that i can use to create a salad/bowl.
The entries should be displayed organized on categories:
- protein
- base
- fresh vegetables/fruits
- cooked vegetables/fruits
- topping
- extras
- souces (i know a souce are more ingredients, but yeah, we consider it as one entry that can be linked to another page in the app or a public url for the recipie)

I want to have 2 little icons that i can add near every entry. One cute icon to represent me and one to represent my girl. This is how i want to show which are our favourite ignredients or the ones that we like. Maybe 3 icons for each (3 for me, 3 for her): love, like, hate.

More, than that, i want a button on this page "Create Bowl" (it can have a more cozy and cute name). You press it and now you can select any ingredient. When you want you can click one of 2 buttons: cancel (canel all selections) or create (creates the recipie).
Very important: while you select ingredients you will probably scroll trhough the page because there are a lot of ingredients so there should be a box always visible so you can see what you already selected and you should be able to deselect something using that box (cancel and create buttons should be in that box too, so they are always visible).
This box should be visible only when we are in selection/creation mode

### Recipe creation

I want to have a list of recipies.
Here i want 2 types of recipies: just a public link that ia dd from the internet AND manual edited recipies that i create by selecting ingredients fron the ingredient list.
So, this means i want another page where i can see all my recipies and filter them using ingredients. Maybe i want to see all that have salomn, etc.
